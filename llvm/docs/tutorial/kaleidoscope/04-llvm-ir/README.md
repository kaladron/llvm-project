# Section 4: Generating LLVM Intermediate Representation

In [Section 3](../03-operators-eval/README.md), you built an Abstract Syntax Tree (AST) with operator precedence and evaluated expressions directly in pure C++.

Now we begin using the LLVM compiler framework.  In this section, you will translate the AST into real LLVM Intermediate Representation (IR).  LLVM IR is a universal, strongly-typed, low-level language in Static Single Assignment (SSA) form that LLVM uses to optimise code and generate machine code for any target architecture.

In this section, you will continue extending your `kaleidoscope.cpp` file in four bite-sized steps.  At each step, you will compile and inspect the real LLVM IR generated by your compiler.

---

## Steps in This Section

1.  [Step 4.1: LLVM Setup and Constant IR](01-llvm-setup.md) - Initialise the LLVM context, module, and IR builder, and emit IR for numeric literals.
2.  [Step 4.2: Binary Math in IR](02-binary-ir.md) - Generate floating-point math instructions (`fadd`, `fsub`, `fmul`, `fdiv`).
3.  [Step 4.3: Function Definitions](03-functions-ir.md) - Define function prototypes, function bodies, and basic blocks.
4.  [Step 4.4: Function Calls and 'extern'](04-calls-and-extern.md) - Call user functions and declare external C standard library functions, plus an active learning challenge.

## Compiling with LLVM Libraries

Beginning in this section, your compiler links against the LLVM core libraries.  To retrieve the necessary compiler include flags and linker flags on your system, use `llvm-config`:

```bash
clang++ -Wall -Wextra kaleidoscope.cpp $(llvm-config --cxxflags --ldflags --system-libs --libs core) -o kaleidoscope
```

Full reference implementations for each step are stored in the [code/](../code/) directory.
